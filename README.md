# 🎫 Ticket Booking REST API

A Spring Boot based RESTful API for online ticket booking.  
This project demonstrates how to build REST APIs with **Spring Boot, Spring Data JPA, and MySQL**, supporting both **JSON** and **XML** response formats.

---

## 🚀 Features
- Book a ticket with passenger details and save it in the database.
- Retrieve ticket details by ticket ID.
- Auto-generated unique ticket ID.
- CRUD operations using **Spring Data JPA** and Hibernate.
- REST API responses available in **JSON & XML** formats.
- APIs tested using **Hoppscotch/Postman**.

---

## 🛠 Tech Stack
- **Backend:** Java, Spring, Spring Boot, Spring Data JPA, Hibernate  
- **Database:** MySQL  
- **API Formats:** JSON, XML  
- **Tools:** Hoppscotch / Postman
